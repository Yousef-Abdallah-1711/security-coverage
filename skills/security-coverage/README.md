# Security Coverage skill package

Install this directory as one Agent Skill. `SKILL.md` is the single source of truth for assessment, planning, and implementation. The supporting references, templates, and optional standard-library detector are relative to this directory.

The skill reads the authorized project repository and writes persistent artifacts under `docs/security/` according to the stage selected by the user. Implementation requires explicit approval for each phase and exact scope. Prompt instructions do not replace host sandbox permissions.

This workflow is not a vulnerability scanner, penetration test, compliance certification, or guarantee of security. Automated signals require human verification.
